## My own rules
These win over the shared rules. Updates never change anything in this section except the one-time machine/helper-name block below (added only if missing).

### My machine (Windows PC)
Use Windows paths. `~` means `C:\Users\<my name>`.
- **Commands I paste:** PowerShell unless I say otherwise; say "PowerShell" in the message. Output worth keeping goes to `logs\<job>-<date-time>.txt` in the project. Waits and steps over 5 seconds show `Write-Progress` (step n of m, what it waits for).
- **Handovers:** `<project>\handovers\<task>.md`; open tasks in `<project>\handovers\ACTIVE.md`.

### Helper names
My helpers are named `helper-<role>`: `helper-planner`, `helper-reviewer`, `helper-builder`, `helper-light`, `helper-medium`, `helper-scout`, `helper-check`.
